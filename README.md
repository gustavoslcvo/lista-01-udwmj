Este repositório foi criado para a realização da atividade da disciplina de UDWmJ.
Funcionalidade
O programa foi desenvolvido em JavaScript e tem como objetivo receber o nome e a idade do usuário.
Após receber essas informações, o programa exibe uma mensagem de apresentação e verifica se a pessoa é maior ou menor de idade.
Funcionamento
O programa utiliza o módulo readline do Node.js para permitir que o usuário digite informações pelo terminal.
Primeiro, o programa solicita o nome do usuário. Em seguida, solicita sua idade.
Depois de receber os dados, utiliza uma estrutura condicional if/else para verificar a idade:
Se a idade for maior ou igual a 18 anos, informa que o usuário é maior de idade.
Se a idade for menor que 18 anos, informa que o usuário é menor de idade.
